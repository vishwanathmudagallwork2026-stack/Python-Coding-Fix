# Python Coding Practice

A personal learning repository for Python fundamentals, functions, control flow, collections, decorators, iterators, and practice exercises.

## Repository structure

- `Python Basics/` — variables, data types, operators, strings, input/output, conditions, and loops.
- `Python/` — additional examples of type conversion, strings, sets, slicing, and built-in functions.
- `30June2026/`, `6July2026/`, `7July2026/`, `8July2026/` — dated control-flow lessons.
- `13July2026/` through `24July2026/` — function, argument, nested-function, decorator, and iterator lessons.
- `Practice/` — small standalone exercises.

## Run an example

Install Python 3.10 or newer, clone the repository, and run one script at a time. For example:

```bash
python "Python Basics/calculator.py"
python "Practice/calender.py"
```

Some scripts ask for input in the terminal. Use quotes around paths that contain spaces.

## Learning notes

These files are small, independent lesson examples rather than one application. Run them individually. Comments explain concepts, and input validation is included where invalid input would otherwise stop an example.

## Maintenance

- Do not commit `__pycache__/`, `.pyc` files, temporary editor runner files, or virtual environments.
- Keep one concept or exercise per file where practical.
- Prefer descriptive file names and consistent lowercase `snake_case.py` naming for new examples.
- Avoid `eval()` on user-supplied input.
